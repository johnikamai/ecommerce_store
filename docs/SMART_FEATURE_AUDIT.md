## Evidence and limits

Fresh evidence stays privately in ignored `.local/feature-browser/`: actual image matching, recorded price graph, compatibility selection, exact bundle/cart/budget amounts, comparison verdict, wishlist persistence, staff approval/restricted dashboard and group settlement. Earlier unchanged feature UI evidence remains in `.local/smart-feature-audit/`. Fresh Gateway tests cover all fifteen feature APIs and owners; some browser features intentionally have no dedicated AI endpoint.

Temporary cart/wishlist entries and the disposable price-history product were removed. Synthetic order/payment/group history remains for audit. Original customer/product records and legacy source data were preserved. Existing unscoped browser-only wishlist settings remain locally; they are not silently assigned to a different account. Re-save desired target/opt-ins in the wishlist to store them with the account.

No cloud deployment, provider charge or real payment was performed. Docker execution, actual managed-provider TLS/grants/restore, external Brevo/Twilio delivery, real CARD/UPI charging and optional external LLM responses are not established by local acceptance.
